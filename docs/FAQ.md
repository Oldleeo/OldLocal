# 常见问题与故障排查

[← 首页](../README.md) · [图文教程](USER_GUIDE.md)

## 安装与兼容

### 下载哪个文件？

Release 的 Assets 中选 `OldLocal-macOS-arm64.zip`，解压得到应用。`Source code` 是源码包，需要自行编译。

### 支持哪些 Mac？

发行包为 Apple Silicon / arm64，构建目标 macOS 15+。真实定位操作在 macOS 15.7.4 验证过，其他版本不能仅凭最低系统要求推断全部兼容。没有发布 Intel、Windows、iOS 版。

### 提示无法验证开发者或无法打开？

下载包采用 ad-hoc 签名，未公证。确认来自 [官方 Release](https://github.com/Oldleeo/OldLocal/releases/latest)，查看「系统设置 → 隐私与安全性」是否提供允许打开选项。系统版本或管理策略可能限制打开；没有相应选项时提供完整提示，勿关闭 SIP。

### 为什么要放在应用程序？

组件只接受指定本机路径 `/Applications/OldLocal.app` 的已批准应用。直接从下载目录运行可以看地图，但不能正常完成该组件的启用。

## 授权与定位

### 每次修改定位都需要密码吗？

不需要。首次启用组件或更新软件签名需要一次管理员授权。已连接的组件处理日常修改、恢复。

### 没有管理员弹窗怎么办？

先看状态：如果组件已就绪，本来就不需要弹窗；如果显示未启用，打开「使用引导 → 启用定位组件」。确认 macOS 弹窗没有在其他窗口后面，按实际系统提示处理。取消或授权失败后重新打开引导再试，不要把密码发送到反馈页面。

### 为什么地图有图钉，其他应用位置不变？

图钉是选点预览。先点击修改或收藏应用，再看状态，并在目标应用查看实际当前位置。Apple Maps 可能缓存位置，可退出后重新打开。其他应用可能使用公网 IP 或自己的来源；OldLocal 不能保证所有应用一致。

### 修改定位会改变 IP、时区或 Wi-Fi 吗？

不会。它写入定位模拟参数，不提供 VPN，不设置时区或网络。IP 区域查询只是查数据。

### 能改连接的 iPhone 吗？

当前不能；这是 Mac 本机工具，不是 iPhone 定位工具。

### 关闭应用就恢复了吗？

不会。结束时手动点击「恢复原定位」，检查结果。退出 OldLocal 也不会自动关闭已应用的模拟位置。

### 「修改未完成，参数已回退」是什么意思？

软件没有把本次修改当成成功，之前参数已回退。打开「查看诊断」记录完整状态；若要结束测试，用「恢复原定位」并核对目标应用。不要只凭主界面预览判断成功，也不要删除备份再试。

### 「参数已恢复，刷新待确认」怎么办？

参数读回已核对，但定位服务刷新没有完全确认。继续检查目标应用；缓存未更新时重开目标应用。保留备份和诊断结果，必要时到 Issues 反馈。

### 恢复到哪里？

恢复最初保存的模拟参数状态，不是上一条收藏，也不是查询 IP 得到的位置。备份为 `/var/db/mac-location-lab/original.json`，由系统权限保护，请勿删除或手动改动。

## 收藏与位置输入

### 怎么删除分组？

收藏分组旁「管理」→ 选择组 →「删除分组」。收藏移到「未分组」，备注、坐标和身份保留。管理窗口内可撤销最近一次操作，关闭后结束；「未分组」受保护。

### 怎么找回删除的收藏？

点击收藏编辑区下方「最近删除」，选条目，点「恢复收藏」。删除收藏不会恢复系统位置。

### 收藏当前位置和更新所选有什么区别？

前者新增一条，后者修改选中的那条。想编辑原收藏，先点卡片，再改备注、分组或坐标，最后「更新所选」。

### 坐标看起来没错却落在别处？

检查纬度在前、经度在后；然后检查数据是否为 WGS84。其他坐标系可能存在偏移，当前不自动转换。

### 搜索没有建议或地图空白？

至少输入两个字符，确认网络能访问地图服务，也可点搜索或回车。服务结果受地区和网络影响；仍失败时记录输入和提示，不把空结果当作已选点。

## IP、更新与数据

### IP 位置为什么不精确？

IP 地理数据库返回区域估计，不是 GPS。VPN、代理、移动网络或数据源会影响结果。查询由 ipapi.co 提供，查询可能有次数限制。

### 更新会删除收藏吗？

手动替换应用不删除用户资料目录中的收藏。请退出应用后再替换，更新后按引导批准组件。当前不支持自动安装。

### 更新面板连接失败？

检查能否访问 GitHub，稍后重试，或点「查看全部版本」。请求次数受限也会失败。软件不会把网络错误显示成「已是最新版」。

### 反馈会自动上传我的数据吗？

不会自动提交；只在浏览器打开预填的 GitHub 问题模板。版本和系统信息预填，坐标、收藏、诊断不自动附带。Issues 是公开的，手动添加的截图也需要自己检查。

### 怎么完整卸载？

1. 打开 OldLocal，先「恢复原定位」并检查状态。
2. 菜单「OldLocal → 移除定位组件…」，按系统提示授权。
3. 退出应用，再从 Finder 删除 OldLocal。

组件移除保留收藏和原定位备份。不要用删除备份的方式代替恢复。

## 仍然有问题？

[提交问题报告](https://github.com/Oldleeo/OldLocal/issues/new?template=bug_report.md)。请提供软件和 macOS 版本、复现步骤、完整状态文字及经过个人信息检查的截图。不要公开管理员密码、访问令牌、私人坐标或原定位备份。
