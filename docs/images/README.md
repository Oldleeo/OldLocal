# 文档配图

配图基于 OldLocal 2.3.0 的 AppKit / MapKit 原生界面。

- 界面采图使用独立的临时演示应用，与正式版共用界面源码。其应用标识、收藏文件及偏好与用户应用分离，定位执行被阻断，不安装或调用系统修改组件。
- 收藏示例为巴黎埃菲尔铁塔、东京塔和首尔市中心等公开地标。
- 搜索补全实际查询 `Seoul`；IP 实际查询公开测试 IP `8.8.8.8`，没有查询用户公网 IP。
- 更新面板读取本仓库的公开正式 Release。
- `cover.png` 是品牌封面，`overview.png` 添加了导航编号，`workflow.png` 是说明流程图。其他图片为界面截图的裁切和排版。
- 图钉只是选点预览。引导中的就绪状态用于展示相应界面，不表示采图时执行了系统定位操作。
- 文档图片不包含用户私人收藏、当前位置、管理员密码或原定位备份。

图片中的地域、网络查询结果、系统样式可能随服务或版本改变；操作名称以当前软件为准。品牌与作者形象使用范围见 [第三方及资源说明](../../THIRD_PARTY_NOTICES.md)。
